# Skillcheck v0.13.0: Daily Developer Habit Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish Skillcheck as an indispensable daily developer habit by adding cascading watch mode with hot-reloading on save (`skillcheck watch`), a native git pre-commit regression guard (`skillcheck hook`), an interactive alternate-screen trial inspector ("Skillcheck Lens"), and checkpointed resumable evaluations (`--resume`).

**Architecture:** Build modular, zero-dependency components under `packages/cli/src/` and `packages/cli/src/ui/`. File watching uses native `node:fs` watchers with debouncing; pre-commit inspection operates directly on `git diff --cached` with micro-eval gates; the inspector runs inside the alternate-screen buffer (`withRawMode`); checkpoints persist atomically with SHA-256 state hashing.

**Tech Stack:** TypeScript, Node.js (`node:fs`, `node:path`, `node:crypto`), Vitest. Zero new runtime npm dependencies.

**Spec:** `ROADMAP.md` (Phase 2: v0.13.0 Daily Developer Habit Loop).

## Global Constraints
- Senior engineering discipline: small, single-purpose functions with explanatory comments.
- Zero speculative abstraction and zero bloat: no external npm dependencies added.
- Modular UI design under `packages/cli/src/ui/`.
- Bounded outbound calls: micro-evals enforce standard timeouts.
- All tests pass: `npm run typecheck && npm run build && npm test && npm run lint`.

## Review Focus
1. Unsaved/ephemeral edits during watch mode: debounce must prevent concurrent evaluation storms on rapid typing.
2. Git hook bypass: pre-commit hook must respect `SKILLCHECK_SKIP_HOOK=1` and `--no-verify`.
3. Inspector terminal restoration: `withRawMode` alternate screen must cleanly restore terminal state on `q` or `SIGINT`.
4. Checkpoint corruption: invalid, partial, or mismatched checkpoint files must be safely ignored without crashing.
5. Path handling: git hook must correctly resolve repository-relative paths when executed from subdirectories.
