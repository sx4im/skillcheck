# Skillcheck v0.12.0: Core Ergonomics & Local Power Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Elevate Skillcheck's terminal ergonomics and local developer experience to match Hermes Agent and OpenCode by adding workspace auto-discovery, zero-config local LLM probing (Ollama/LM Studio), zero-binary OSC 52 clipboard export, native shell completions (bash/zsh/fish), fuzzy search filtering in the file picker, and live dual-arm telemetry.

**Architecture:** Implement modular, zero-dependency components under `packages/cli/src/` and `packages/cli/src/ui/` with strictly bounded timeouts (100ms for local probing), zero platform binaries for clipboard copy (OSC 52 escape sequences), pure POSIX shell completions, and in-memory substring scoring for fuzzy picking.

**Tech Stack:** TypeScript, Node.js (`node:fs`, `node:path`, `node:http`), Vitest. Zero new runtime npm dependencies.

**Spec:** `ROADMAP.md` (Phase 1: v0.12.0 Core Ergonomics & Local Power).

## Global Constraints
- Senior engineering discipline: small, single-purpose functions with explanatory comments.
- Zero speculative abstraction and zero bloat: no external npm dependencies added.
- Modular UI design under `packages/cli/src/ui/`.
- Bounded outbound calls: local probes enforce `AbortSignal.timeout(100)`.
- All tests pass: `npm run typecheck && npm test && npm run lint`.

## Review Focus
1. Non-git workspace directories: `findWorkspaceSkills` must safely handle missing `.git` without throwing.
2. Unresponsive local servers: `detectLocalLlm` must gracefully abort within 100ms without stalling the CLI startup.
3. Terminal clipboard compatibility: OSC 52 copy must gracefully fallback without throwing if stdout is redirected or non-TTY.
4. Shell completion safety: Shell completion generators must produce valid syntax without unescaped characters.
5. Fuzzy picker keyboard navigation: Typing search queries must not break arrow keys, window scrolling, or enter/escape keys.
