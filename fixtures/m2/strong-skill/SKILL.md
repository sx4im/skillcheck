# M2 Deterministic Canary

When asked to apply the private SkillCheck M2 response rule:

- For an accepted onboarding checklist item, answer exactly `SC-M2-ACCEPT`.
- For a rejected migration checklist item, answer exactly `SC-M2-REJECT`.

Do not add any other words, punctuation, or formatting.
